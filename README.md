# 👵 Senior Care AI Assistant / 高齡照護 AI 助手

一個專為長者與其家屬設計的無障礙、多模態（語音、視覺、文字）智慧照護系統。

本專案採用 **Streamlit** 建構互動介面，整合 **OpenAI GPT-4o、Whisper、TTS** 以及 **LINE Messaging API**，打造具備情感陪伴、智慧健康隨身查、用藥安全防護與家屬分天檢閱功能的智慧高齡照護平台。

---

# 專案背景

隨著高齡化社會快速發展，許多長者與獨居老人面臨以下照護痛點：
* 缺乏日常陪伴與情感支持，容易產生孤單與焦慮感。
* 用藥資訊繁雜、藥袋字體過小，導致長者容易忘記或混淆服藥時間。
* 家屬與長者分居兩地，難以及時且精確地掌握長者每日的真實身心近況。
* 傳統數位產品與通訊軟體操作門檻過高，長者難以跨越數位落差。

因此，本專案透過生成式 AI、多模態情境感知與「零操作門檻」設計，打造一位兼具安全預警與親情溫度的 AI 照護小幫手，在提升長者生活品質的同時，大幅降低遠端家屬的照護焦慮。

---

# 專案目標

本系統聚焦於以下三大照護核心需求：

### 🧬 情感陪伴與隨身查
以長輩熟悉的孫輩語氣進行全語音聊天，並動態整合生活與藥物資料庫，隨時回答長者疑問。

### 🚨 救命級安全防預
建立全天候語意風險攔截網，發生不適時立即在長者端進行語音引導，並秒級同步群發警告給家屬。

### 📊 家屬智慧協作
將每日互動與服藥日誌進行分天歸檔封存，利用大語言模型為家屬產出結構化的每日照護個管報告。

# 核心功能

## 1. AI 溫柔陪聊與智慧隨身查系統
系統以「孫子／孫女」角色進行日常陪伴，提供溫暖、具同理心的聊天體驗，而非傳統客服式問答。

### 功能特色
* **全語音雙向互動**：長者免打字，一鍵點擊大按鈕即可錄音聊天；系統自動調用擬真人聲緩慢播報回覆。
* **🗣️ 語音藥物隨身查**：系統自動將已解析的藥單資訊動態注入 AI 上下文。長者聊天時可以直接用問的（例如：「我那個白色的藥要怎麼吃？」），AI 就會自動翻查記憶庫並溫柔口頭解答。
* **時空情境感知問候**：自動連動**民雄即時天氣**轉化為出門或飲水叮嚀；並智慧推算當天的**農曆日期、二十四節氣與傳統節日**進行節慶問候。
* **智慧雙語匹配**：精準實現中英輸入輸出獨立，對話絕不語系混亂。

### 技術實作
| 功能 | 技術 |
| :--- | :--- |
| 語音辨識 (STT) | OpenAI Whisper-1 |
| 對話生成與推理 | OpenAI GPT-4o-mini |
| 語音合成 (TTS) | OpenAI TTS-1（支援4種音色切換） |
| 即時氣象連動 | [wttr.in API](https://wttr.in/) |
| 本地記憶庫 | JSON Local Storage |
|移動裝置展示|[Ngork](https://ngrok.com/)|

---

## 2. 藥袋 OCR 智慧解析與用藥清單

### 功能特色
* **視覺結構化抽取**：長者或家屬只需拍攝藥袋相片上傳，系統便啟動 **GPT-4o 視覺大模型**進行密集推理，精準將混雜文字轉化為清晰的中英文藥名、服用時段、單次劑量與藥物外觀描述。
* **叮嚀語音導讀**：解析完成後，自動將複雜醫囑轉換為孫輩語氣的口頭服藥提醒稿，並轉為 TTS 語音自動播放。
* **行事曆連動**：清單旁附帶 Google Calendar 同步按鈕。內建動態日期防護參數（`&dates`），一鍵點擊即可免 API 驗證跨裝置（Android / iOS）寫入服藥排程與系統原生定時提醒。

### 處理流程
```text
藥袋拍照上傳 → GPT-4o Vision → 結構化 JSON 欄位 → 生成孫輩導讀語音 → 同步至用藥清單與行事曆

```

---

## 3. 店家級 LINE 緊急防護群發系統

為確保高風險健康事件能在第一時間獲得處置，系統設計了「長者端引導」與「家屬端空投訊息」的雙路防禦網。

### 功能特色

* **關鍵字風險偵測**：對話時監控「胸痛、跌倒、喘不過氣、暈、不舒服」等中英文高風險健康關鍵字。
* **長者端語音引導**：觸發時中斷陪聊流程，網頁跳出紅色高亮警告，並強制播放引導就地休息、撥打 119 的緊急語音。
* **家屬端 LINE 秒級群發**：系統免除繁瑣的個人 User ID 認證，改採 **LINE Messaging API Broadcast（廣播接口）**。家屬只要用手機掃描網頁上的按鈕加入好友，發生不適時，**全體家屬的手機 LINE 將同步收到內含「長者不舒服原話」的紅色緊急通知**。

### 處理流程

```text
長者提及不適 (如：我胸口好痛)
          │
          ▼
   [ 關鍵字風險偵測 ]
          │
    ┌─────┴────────────────────────────────┐
    ▼                                      ▼
[ 長者端網頁 ]                        [ 家屬端 LINE 群群發 ]
- 顯示紅色高亮錯誤警告 (st.error)      - LINE Bot 秒級啟動廣播接口
- 強制播放 119/就地休息引導語音         - 全體已加好友之家屬手機同時響起
                                      - 訊息內完整附帶長者不舒服原話

```

---

## 4. 數位健康日誌與安心報平安（家屬專區）

本系統將家屬與長者介面分開，讓功能導向更加清晰易用。

### 功能特色

* **✅ 服藥確認與安心回報**：長者吃完藥在清單打勾，系統會永久封存該次服藥的時間戳記，並**瞬間發送 LINE 訊息向全體家屬報平安**（例如：「阿公剛剛已確認服用晚上飯後的藥物」）。
* **📅 當天紀錄分天檢閱**：引入 `st.date_input` 日期選取器。系統每天跨日會自動重置打勾狀態，家屬可自由點選日曆，跨天翻查長者在「指定某一天」的**詳細聊天對話日誌**與**實際服藥確認時間點**。頁面並附帶一鍵清除該日資料的除錯按鈕。
* **📊 個管師 AI 報告生成**：家屬可一鍵呼叫 **GPT-4o**，針對該選定日期的所有聊天歷史與用藥數據進行深度摘要，產出包含「情緒精神、身體不適點、用藥順從度」三大面向的結構化個案報告。

# 技術棧

### 前端介面

* **Streamlit** (基於 Python 的響應式網頁框架)
* **Custom CSS**（針對高齡視力優化的全網頁大字體、大按鈕無障礙設計）

### 後端與 AI 模型

* **OpenAI GPT-4o** (旗艦級視覺與文本分析模型，用於藥袋 OCR、個管報告生成)
* **OpenAI GPT-4o-mini** (高效能對話推理模型，用於日常陪聊與智慧隨身查)
* **OpenAI Whisper-1** (高精準度語音轉文字) → 但其實用手機或電腦內建麥可風即可
* **OpenAI TTS-1** (低延遲文字轉語音)

### 資料儲存與第三方連動

* **JSON Local Storage** (本地輕量化持久儲存，最大化保障長者隱私)
* **LINE Messaging API (Broadcast 接口)** (店家級全體群發訂閱系統)
* **wttr.in Weather API** (民雄鄉定時天氣串接)
* **Google Calendar Template URL** (跨裝置行事曆排程連動)

# 本地端執行與環境配置

## Step 1: Clone 專案

```bash
git clone [https://github.com/SnackeyesBoy/Senior-Care-AI-Assistant.git](https://github.com/SnackeyesBoy/Senior-Care-AI-Assistant.git)
cd Senior-Care-AI-Assistant

```

## Step 2: 安裝依賴套件

```bash
pip install -r requirements.txt

```

## Step 3: 設定變數隔離 (.env)

在專案根目錄下建立 `.env` 檔案，填入以下環境變數：

```env
OPENAI_API_KEY=你的OpenAI金鑰(sk-...)
LINE_CHANNEL_ACCESS_TOKEN=你的LINE機器人ChannelAccessToken

```

*(註：採用 Broadcast 群發技術，無需再逐一填寫煩人的個人 LINE USER ID)*

## Step 4: 啟動智慧照護系統

```bash
streamlit run app.py

```

## Step 5: 移動裝置展示

```bash
ngork https 8051

```

# 專案價值

Senior Care AI Assistant 絕非傳統生硬的聊天機器人，而是一套將情感陪伴（Emotional Support）、用藥管理（Medication Management）、風險預警（Risk Detection）與家屬協作（Family Collaboration）四大長照核心剛需完美融為一體的多模態智慧高齡照護平台。

系統透過全域變數優化與店家級 LINE 群發防護，解決了傳統系統部署繁瑣、變數易崩潰的工程挑戰。以科技展現人文關懷，協助長者擁有更安全、更自主、更有尊嚴的生活品質。
