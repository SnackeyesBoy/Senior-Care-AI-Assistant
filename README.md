# 👵 Senior Care AI Assistant / 高齡照護 AI 助手

一個專為長者與其家屬設計的無障礙、多模態（語音、視覺、文字）智慧照護系統。

本專案採用 **Streamlit** 建構互動介面，整合 **OpenAI GPT-4o、Whisper、TTS** 等生成式 AI 技術，打造具備情感陪伴、健康關懷、用藥管理與家屬協作功能的智慧照護平台。

---

# 📖 專案背景

隨著高齡化社會快速發展，許多長者面臨以下問題：

* 缺乏日常陪伴與情感支持
* 獨居生活容易產生孤單與焦慮感
* 用藥資訊複雜，容易忘記服藥時間
* 家屬難以及時掌握長者近期狀況
* 傳統數位產品操作門檻較高

因此，本專案希望透過生成式 AI、多模態互動技術與智慧照護設計，打造一位能夠陪伴、關心、提醒與協助長者的 AI 助手，提升長者生活品質，同時降低家屬照護負擔。

---

# 🎯 專案目標

本系統聚焦於以下三大照護需求：

### 💬 情感陪伴

透過自然語言與語音互動，提供溫暖且具同理心的聊天體驗，降低長者孤獨感。

### 💊 用藥管理

利用 AI 視覺辨識與 OCR 技術，自動解析藥袋資訊並建立提醒機制。

### 👨‍👩‍👧 家屬協作

自動生成健康與互動摘要報告，協助家屬掌握長者近期身心狀況。

---

# ✨ 核心功能

## 💬 AI 溫柔陪聊系統

系統以「孫子／孫女」角色進行陪伴，而非傳統客服式問答。

### 功能特色

* 支援文字與語音雙模式互動
* 提供情緒支持與正向鼓勵
* 長期記憶與個人化關懷
* 根據時間與天氣進行生活提醒
* 自動偵測中文與英文並切換回覆語言

### 技術實作

| 功能        | 技術           |
| --------- | ------------ |
| 語音辨識(STT) | Whisper-1    |
| 對話生成      | GPT-4o-mini  |
| 語音合成(TTS) | TTS-1        |
| 長期記憶      | JSON Storage |

---

## 🧠 個人化記憶系統

系統會記錄長者的重要資訊，例如：

* 慢性病史
* 生活習慣
* 飲食偏好
* 家庭成員資訊
* 近期健康狀況

並於後續對話中自然融入，提升陪伴真實感與照護品質。

例如：

> 阿公上次提到膝蓋有點不舒服，最近有比較好一些嗎？

---

## 🌦️ 情境感知陪伴

系統能結合：

* 即時時間
* 即時天氣
* 近期互動內容

自動生成貼近生活的關懷內容。

例如：

* 天氣炎熱時提醒補充水分
* 天氣變冷時提醒注意保暖
* 晚間時段提醒早點休息

讓 AI 更貼近真實照護情境。

---

## 🚨 危險症狀即時警示系統

為避免高風險健康事件被忽略，系統設計了安全監測機制。

### 高風險關鍵字範例

中文：

* 胸痛
* 跌倒
* 呼吸困難
* 昏倒
* 大量出血

英文：

* chest pain
* fall
* can't breathe
* unconscious

### 處理流程

```text
使用者輸入
      ↓
關鍵字風險偵測
      ↓
中斷一般聊天流程
      ↓
顯示警示訊息
      ↓
播放緊急語音提醒
      ↓
建議聯絡家屬或 119
```

---

## 📷 藥袋 OCR 智慧解析

長者只需拍攝藥袋照片，系統即可自動辨識內容。

### AI 自動擷取資訊

* 藥品名稱
* 劑量
* 服用方式
* 服藥時間
* 注意事項
* 藥物外觀描述

### 處理流程

```text
藥袋拍照
    ↓
圖片上傳
    ↓
GPT-4o Vision
    ↓
資訊結構化解析
    ↓
建立用藥提醒
```

---

## 📅 Google Calendar 用藥提醒

藥袋解析完成後，系統可自動產生 Google Calendar 行程。

支援：

* 早餐後服用
* 午餐後服用
* 晚餐後服用
* 睡前服用

使用者僅需點擊按鈕即可同步至：

* Android
* iPhone
* Google Workspace

實現跨裝置提醒。

---

## 📊 家屬健康報告系統

系統定期分析：

* 聊天紀錄
* 用藥資訊
* 健康狀態
* 情緒變化

並產生結構化報告。

### 報告內容

#### 🩺 健康摘要

* 疼痛狀況
* 睡眠品質
* 食慾狀況
* 行動能力

#### 😊 情緒分析

* 正向
* 中性
* 焦慮
* 低落

#### 💊 用藥追蹤

* 服藥紀錄
* 新增藥物
* 異常描述

協助家屬快速掌握長者近況。

# 🚀 本地端執行

## 1️⃣ Clone 專案

```bash
git clone https://github.com/SnackeyesBoy/Senior-Care-AI-Assistant.git
cd Senior-Care-AI-Assistant
```

## 2️⃣ 安裝套件

```bash
pip install -r requirements.txt
```

## 3️⃣ 設定環境變數

建立 `.env`

```env
OPENAI_API_KEY=your_api_key
```

## 4️⃣ 啟動系統

```bash
streamlit run app.py
```

## 5️⃣ 本地部署（手機）

```bash
 ngrok http 8501                
```

# 🔬 技術挑戰與解決方案

### 長者語言切換問題

採用 Dynamic Language Switching 與 Late Prompting 技術，實現中英文自動切換。

### 藥袋格式不統一

使用 GPT-4o Vision 進行語意理解，提升解析成功率。

### AI 醫療安全問題

建立風險關鍵字攔截機制與緊急提醒流程。

### 高齡者操作門檻

全面支援語音互動與大字體介面設計。
